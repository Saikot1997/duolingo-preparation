DET Prep (offline)
1. Open index.html in Chrome (double-click).
2. Photo exams (Write/Speak About the Photo) look for images in assets/img/.
   Keep your downloaded images folder there. If a file is missing, the app tries the online link, then shows a placeholder.
3. Progress is saved in your browser (localStorage). Plan page > "Reset all progress" clears it.
Source for task formats/timings: Duolingo English Test Scoring Guide for Teachers (2026).
